# Android 数据与权限说明

本说明描述 recoow Android 客户端的数据处理方式。同步服务器由使用者配置；服务器运营方的数据保存期限、账号删除方式和联系渠道，应以该运营方提供的说明为准。

## 记录与附件

账单、打卡、日记、饮食、物品、纪念日、抽选历史和轨迹保存在应用私有目录。照片、录音和素材可能包含个人信息。图片选取通过系统选择器，仅处理用户选择的文件；拍照由系统相机完成。图片会经过方向校正、缩放和 JPEG 压缩。

录音需要用户主动开始，仅在前台进行；离开页面、进入后台或失去音频焦点时停止录音并释放设备。日记中的位置由用户主动获取。轨迹记录由用户在前台开始，通过持续显示的前台服务记录位置，用户可以暂停或结束。

“拍照保存到系统图库”会在应用目录之外保存照片。删除应用中的记录或卸载应用，不会自动删除这些图库副本。

## 联网与同步

未连接同步服务器时，记录可在本机使用。开启同步后，记录、附件及用于同步的设备标识、变更和删除标记会发送到配置的服务器。关闭同步会停止手动和自动同步，但不会删除服务器或其他设备上已有的副本。正式客户端要求 HTTPS；传输加密不等于端到端加密。同步凭据使用 Android Keystore 保护。

打开在线地图时，客户端从 [OpenFreeMap](https://openfreemap.org/) 请求样式和地图资源。地图服务可以获得网络请求的 IP 地址和所请求的地图区域；浏览当前位置或轨迹附近的地图可能暴露相应区域。地图署名保留在地图界面。地图源和同步服务器是不同的服务。

## 权限用途

| 权限 | 使用场景 |
| --- | --- |
| 精确/大致位置 | 主动获取日记位置、录制轨迹；选择大致位置会影响精度 |
| 麦克风 | 用户主动录制日记或饮食语音附件 |
| 通知 | 打卡、纪念日提醒和轨迹录制状态；拒绝不影响本地记录保存 |
| 精确闹钟特殊访问 | 更准确地安排提醒；未允许时使用非精确调度 |
| 前台服务及位置服务类型 | 用户开始录制后的持续轨迹采样 |
| 旧版存储读写（仅 Android 8–9 / API26–28） | 兼容旧系统的“拍照保存到系统图库”；拒绝时仍可保存应用私有照片 |
| 网络、网络/Wi-Fi 状态 | 用户配置的同步服务与在线地图、网络任务调度 |
| 开机广播、唤醒锁 | 恢复提醒和调度持久化后台任务 |

客户端不申请后台位置、全文件管理或 Android 13+ 的整库图片/视频读取权限。系统相册选择器不需要整库授权。权限可以在系统应用设置中撤销；系统强行停止应用后，需要重新打开才能恢复后台工作。

## 导出、删除与重置

导出的备份包含业务记录、媒体和可迁移偏好，是可读取的 SQLite 文件，不附带密码加密。请将备份保存在可信位置；文件的分享和外部保存位置由用户选择。

删除记录会按业务规则写入删除标记，以便同步到其他副本。同步历史、冲突和本机回滚备份可能继续引用相关数据；存储优化会保留这些必要引用，不等同于立即擦除所有历史副本。

“重置本机数据”清除本机记录、私有媒体、连接信息和偏好，并清理本机回滚及临时文件；它不注销远端账号，也不删除远端服务器、其他设备、用户导出的备份或系统图库副本。重新连接原账号后，服务器数据可能重新同步到本机。远端账号及数据删除应联系相应服务器运营方。

系统自动应用备份已关闭；应用内显式导出与回滚备份仍按上述规则工作。
