# recoow Web

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

recoow 用户在电脑或手机浏览器中查阅已经同步的个人记录、统计和修改历史。

## Product Purpose

提供统一的云端只读工作台。用户能快速找到记录，理解统计范围，并追溯什么时候修改、什么时候同步以及编辑和提交的设备来源。

## Operating Context

记录主要在 iOS、Android 上产生，可离线编辑后同步。Web 以服务端已接受的数据为准，按浏览器时区显示时间；修改时间与服务端接受时间分别展示。

## Capabilities and Constraints

- Svelte 5、SvelteKit、TypeScript；静态站点与 Go API 同源部署。
- 21 类实体查询、搜索和日期筛选、基础统计、变更历史与字段差异、媒体预览、设备查看。
- Web 会话只读，支持登录、退出；不增加业务写入、账号管理或离线写入队列。
- Cookie 鉴权，业务查询仅在内存中缓存；账号切换、失效和数据世代变化清理旧数据。
- 金额采用精确整数分；不在界面中丢失大整数、未知字段、空值或缺省状态。
- 浅色、深色、跟随系统；简体中文、English、跟随系统。

## Brand Commitments

- 保留 recoow 名称，Web 品牌与站点图标复用客户端 App 图标。
- 不重复显示云端、只读、在线范围说明；异常离线及失败仍提供必要反馈。
- 用户确认整体重做 Web，采用传统后台工作台的布局与控件习惯。
- 布局位置合理、交互自然、样式协调；数据一目了然，间距统一。
- 优先使用成熟的第三方组件，延续现有 Svelte 技术栈。

## Evidence on Hand

现有 routes 与 OpenAPI 契约。

## Product Principles

- 将数据和操作路径放在首位，说明文字就近提供。
- 相同动作使用相同控件、命名、间距和状态反馈。
- 分类及类型名称与 iOS、Android 保持一致；共享素材独立入口。
- 清晰呈现云端时间、编辑来源与提交来源，缺失信息保持未知。
- 只呈现服务端授权的功能，不通过界面或 Header 提升权限。

## Accessibility & Inclusion

所有控件可通过键盘使用，具有明确的名称和焦点；支持窄屏、放大文字、浅深色和减少动画偏好。
