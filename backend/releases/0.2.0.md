## 更新内容

- 原数据账号可设置密码并自动生成用户名，支持移动端密码登录和恢复密钥重设密码；密码统一为 6–18 个字符。
- 记录云端变更历史，提供前后快照、字段差异、客户端修改时间与服务器接受时间；登记设备和离线修改来源。
- 首次绑定及备份恢复支持目录比对和按需读取快照，保留现有增量同步、冲突处理与旧客户端回退流程。
- 首版 Web 会话采用只读权限，可查询记录、统计、历史和媒体；修改密码或找回密码后撤销 Web 会话，已绑定设备保留。
- 公共接口字段统一为 snake_case；迁移期间继续接受旧请求字段并保留已识别旧客户端的响应格式。

## 部署说明

- 升级需执行 `0002_change_events.sql` 和 `0003_device_profiles.sql` 迁移，补充历史事件、只读会话范围与设备来源字段。
- 既有历史中无法确认的服务器时间和来源保持未知，不补造旧记录的元数据；数据集世代与现有账号归属保留。
- 部署前备份数据库和媒体；迁移角色只用于升级，运行进程继续使用普通数据库角色。
- 后端先升级，Web 和移动端随后按兼容契约分别发布，版本号独立管理。
