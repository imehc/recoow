## 更新内容

- 精确比较 JSON 数值，修复轨迹等记录因 `0`、`0.0` 或等值科学计数法造成的误报冲突；保留大整数精度。
- 媒体存储路径和存储后端不再作为业务差异，实际媒体校验和变化仍会产生冲突。
- 新增主设备专用 `DELETE /api/sync/dataset?generation=...`，清空当前账号的业务数据、媒体字节、历史和回执，保留身份与设备绑定，并更换同步世代。
- 清空与正在进行的同步、媒体传输串行校验，旧世代请求被拒绝。

## 部署说明

- 运行包包含 Linux amd64/arm64 API、worker、OpenAPI 契约及部署脚本；使用 `run.sh --verify` 校验。
- 本次更新不更改数据表版本或备份格式，不会主动清空现有数据；清空必须由主设备在应用内确认。
- 管理员保存的离线服务器备份不受应用内清空操作影响。
